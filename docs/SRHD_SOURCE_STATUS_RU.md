## Обязательные правила при следующих правках

1. Не удалять и не перезаписывать сохранённые рабочие версии без сравнения исходников и проверки.
2. Там, где используется Rangers.exe, **оба EXE** (старый и новый); выбор автоматически по хешу, без ручного UI.
3. В каждом моде TEST ↔ RELEASE, по возможности переключатель в конфигурации; не использовать выдуманный `Build=RELEASE`.
4. Сборка и тест в игре обязательны перед объявлением версии рабочей. Готовые ZIP/RAR остаются в Drive.
5. Не размещать в публичном GitHub реальные серверные секреты или приватные ключи.
